\chapter{Introduction}

Learning to program is a long process that can be divided into two phases. The first phase is learning the basic programming skills, such as how to use variables, conditions, loops, and arrays. Basic programming courses cover these topics. The second phase, which we focus on in this course, is learning to create \emph{efficient} algorithms.

When we encounter a programming problem, it is a gateway to an adventure where many challenges may await. All methods are permitted, as long as we create an algorithm that solves the problem efficiently. This course teaches many techniques and ideas that are useful in solving algorithmic problems.

Algorithm design holds a central position in theoretical computer science research, but efficient algorithms are also important in many practical applications. Throughout the course, we will continuously observe the connection between theoretical results and how well algorithms work in practice.
